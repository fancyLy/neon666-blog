欢迎来到Neon的学习笔记

发表于2026-03-24|更新于2026-03-25|公告

🎉 欢迎！

欢迎来到我的个人博客！这里将记录我的学习历程、技术笔记和成长心得。

📚 关于这个博客

这个博客使用以下技术栈构建：

  • Hexo - 静态博客生成器
  • Butterfly主题 - 美观的技术风格主题
  • GitHub Pages - 免费托管
  • GitHub Actions - 自动化部署

🎯 博客目标

  1. 记录学习过程 - 整理和总结学到的知识
  2. 分享技术心得 - 与大家交流编程经验
  3. 建立知识体系 - 将零散的知识系统化
  4. 持续进步 - 通过写作加深理解

📝 内容规划

未来将分享以下内容：

编程技术

  • Python/JavaScript学习笔记
  • Web开发相关技术
  • 算法与数据结构
  • 工具和效率提升

学习心得

  • 学习方法论
  • 时间管理
  • 读书笔记
  • 成长思考

项目实践

  • 个人项目分享
  • 开源项目贡献
  • 技术解决方案

🔧 技术特色

这个博客具备以下功能：

  1. 响应式设计 - 在手机和电脑上都能良好显示
  2. 代码高亮 - 支持多种编程语言的代码展示
  3. 搜索功能 - 快速找到需要的文章
  4. 评论系统 - 使用Giscus基于GitHub Discussions
  5. 夜间模式 - 保护眼睛，适合夜间阅读
  6. 数学公式 - 支持LaTeX数学公式渲染

🚀 开始使用

如果你也是技术爱好者，欢迎：

  1. 订阅更新 - 通过RSS关注最新文章
  2. 参与讨论 - 在文章下方留言交流
  3. 分享建议 - 有任何想法都可以告诉我
  4. 一起学习 - 互相鼓励，共同进步

📬 联系我

  • 邮箱: neon@neon666.xyz
  • GitHub: fancyLy

💭 写在最后

“The only way to learn a new programming language is by writing programs in it.” - Dennis Ritchie

学习是一个持续的过程，写作是巩固知识的最好方式之一。希望通过这个博客，不仅能记录自己的成长，也能帮助到有同样兴趣的朋友。

让我们一起在技术的道路上不断前行！ 🚀
